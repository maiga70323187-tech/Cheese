# Assets d'exemple

Fichiers **placeholders originaux** servant à vérifier la scène
`asset-showcase` par un vrai rendu (voir SCENES.md / ASSETS.md) :

- `sample-logo.svg` — logo vectoriel abstrait (œuvre originale) pour le
  cadrage `brand`.
- `sample-portrait.png` — PNG transparent généré procéduralement (disque
  dégradé) pour les cadrages `person` / `illustration`.

Ce ne sont pas de vrais logos de marque ni de vraies photos : en
production, le champ `src` d'une scène `asset-showcase` est rempli par la
couche de résolution (`src/assets/`, voir ASSETS.md) ou par un fichier que
tu déposes ici toi-même, dûment licencié.
